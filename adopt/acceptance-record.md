# Analytics Acceptance Record

Proposed reusable template. This record does not establish that a review occurred until evidence and accountable decisions are entered. Use one record for a defined release and intended use.

| Source snapshot and as-of date | |

| Execution results and evidence links | |
| Checker dependencies and shared inputs | |
| Technical reviewer, date and review scope | |
| Reader review, reviewer type and exact specimen | |
| Failed criteria and unresolved findings | |
| Exception decision, authority, date and rationale | |
| Residual uncertainty and restrictions on use | |
| Acceptance decision: accept, restrict or refuse | |
| Owner acceptance date and rationale | |
| Changes requiring renewed acceptance | |
| Freshness threshold and escalation contact | |
| Authority to stop publication or use | |

For each exception, retain the original criterion and result alongside the disposition. For a corrected evaluation, retain both versions and state which results had already been seen. For a simulated reader review, identify that limitation explicitly.
